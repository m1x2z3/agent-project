# 提交记录

本目录记录项目每次 Git commit 的主要变更，方便回顾开发过程和准备面试素材。

## 记录内容

每次提交对应一个 Markdown 文件，至少包含：

- 提交时间
- Commit
- 提交说明
- 变更内容
- 涉及文件
- 验证结果

## 文件命名

```text
YYYY-MM-DD-提交主题.md
```

例如：

```text
2026-11-16-重构配置常量定义.md
```

## 提交流程

1. 完成功能修改和测试。
2. 在本目录新增本次提交记录。
3. 使用 `git add` 添加代码和记录文件。
4. 使用 `git commit` 提交。
5. 需要同步 GitHub 时，再执行 `git push`。

记录文件与代码一起提交，确保代码版本和开发说明保持同步。

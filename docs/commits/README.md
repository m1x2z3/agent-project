# 提交记录

本目录按天记录项目每次 Git commit 的主要变更，方便回顾开发过程和准备面试素材。

## 目录结构

```text
docs/commits/
├── README.md
└── YYYY-MM-DD/
    ├── README.md
    └── 每次提交记录.md
```

## 记录内容

每次提交对应一个 Markdown 文件，至少包含：

- 提交时间
- Commit
- 提交说明
- 变更内容
- 涉及文件
- 验证结果

## 每日目录

```text
YYYY-MM-DD/
```

例如：

```text
2026-11-16/
```

每天的提交记录放在对应日期目录下，并在该目录的 `README.md` 中维护当天提交索引。

## 提交流程

1. 完成功能修改和测试。
2. 在当天日期目录新增本次提交记录。
3. 更新当天日期目录的 `README.md`。
4. 使用 `git add` 添加代码和记录文件。
5. 使用 `git commit` 提交。
6. 需要同步 GitHub 时，再执行 `git push`。

记录文件与代码一起提交，确保代码版本和开发说明保持同步。
